# Personal Portfolio Website

A personal portfolio website built using **HTML5 and CSS3** to showcase my profile, technical skills, educational background, and projects. The website features a modern dark-themed interface, structured content sections, interactive hover effects, and a responsive layout.

## 📌 Overview

This project represents my journey as a first-year Computer Science Engineering student specializing in Artificial Intelligence and Machine Learning. It serves as a central place to present my technical interests, academic background, and development projects.

The primary focus of this project was to practice front-end development fundamentals, improve my understanding of CSS layouts, and create a clean, organized, and visually appealing portfolio.

## ✨ Features

* **Profile Sidebar:** Displays my profile photo, name, professional interests, contact information, and social links.
* **About Me Section:** Introduces my academic background and interests in AI/ML, competitive programming, and emerging technologies.
* **Skills Section:** Showcases my current technical skills through visual cards for HTML5, CSS3, C++, and Python.
* **Education Section:** Presents my academic background in a timeline-style layout.
* **Projects Section:** Displays project cards with descriptions and technology tags.
* **Navigation Menu:** Provides links to different sections of the portfolio using HTML anchor links.
* **Dark Theme:** Uses a dark background with amber accents for a consistent visual appearance.
* **Interactive Hover Effects:** Adds transitions, scaling effects, and subtle shadows to selected elements.
* **Responsive Layout:** Uses CSS Grid, Flexbox, and media queries to adapt the layout to different screen sizes.

## 🎨 Design and Layout

The website follows a minimal dark-themed design with clear visual separation between the sidebar and the main content area.

* **Background:** Dark charcoal
* **Content Cards:** Slightly lighter dark gray
* **Accent Color:** Amber/gold
* **Text:** Light gray and off-white
* **Layout:** Two-column desktop layout with a sidebar and main content section

The sidebar uses a sticky position on larger screens to keep profile information accessible while browsing the main content. CSS Grid handles the primary page layout, while Flexbox helps arrange navigation links. Media queries adjust the layout for smaller screens.
